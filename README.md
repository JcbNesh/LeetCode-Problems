**LeetCode Problems**

- **Project:**: A personal collection of solved LeetCode problems organized by topic and difficulty.
- **Purpose:**: Track solutions, reasoning, and runnable examples for practice and interview preparation.

**Repository Structure**
- **`LeetCode 75/`**: curated subset grouped by the "LeetCode 75" pattern.
- **`Array_String/`**, **`Dynamic_Programming/`**, etc.: folders grouped by topic.
- **File names**: Use `ID._Problem_Name.extension` (e.g., `1768._Merge_Strings_Alternately..js`).

**How To Run Solutions (JavaScript)**
- **Run a single file:** from repository root in PowerShell for example run:

```powershell
node "Array_String/1768._Merge_Strings_Alternately.js"
```

**Naming & Documentation Convention**
- **Header comment:** one-line problem description, approach summary, complexity (time/space), and example usage.
- **Examples:** put a few example `console.log` calls at the bottom of the file for quick verification.

Enjoy coding!
